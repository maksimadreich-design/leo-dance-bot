# 🩰 Telegram-бот для LEO DANCE STUDIO (м. Дрогобич)

Індивідуальний бот для автоматизації запису, обліку абонементів та контролю відвідувань танцювальної студії **Leo Dance Studio** (керівник @_ireeendtk, тренер @\_kariina.a\_).

---

## 🌟 Що вже закладено всередині:

1. **Реальний розклад студії (вул. Грушевського 148 Б):**
   - **Понеділок / Середа:** Діти 6-8 років (16:00), Діти 9-11 років (17:20), Малюки 4-5 років (18:30 та 19:20).
   - **Вівторок / Четвер:** Діти 8-10 років (16:00), Підлітки 12-15 років (17:00), Малюки 3-4 рочки (18:15), **High Heels Основна** (19:00), **High Heels Початківці** (20:00).
   - **П'ятниця:** **CHOREO** (18:00).

2. **Для клієнток та дівчат:**
   - 🩰 Запис на тренування в 1 клік з контролем місткості залу (макс 14 людей).
   - 🎟 Перегляд балансу занять та терміну дії абонемента.
   - 💳 Вибір та покупка абонементів (8 занять, 12 занять, пробне, разове).
   - 📍 Локація, телефон та посилання на Instagram.

3. **Для тренерів та керівника (Адмін-панель):**
   - Швидка відмітка присутніх на тренуванні: кнопка «Прийшла» автоматично списує 1 заняття з абонемента та надсилає клієнтці приємне повідомлення після заняття.
   - Кнопка «Хворіла» зберігає заняття за клієнтом.
   - База клієнток з номерами телефонів та залишками занять.
   - Автоматична розсилка тим, у кого закінчується абонемент (1 або 0 занять).

---

## 🚀 Як запустити бота

1. Створіть бота в [@BotFather](https://t.me/botfather) і скопіюйте токен.
2. Дізнайтеся свій Telegram ID через [@userinfobot](https://t.me/userinfobot).
3. Створіть файл `.env` у цій папці (на основі `.env.example`):
   ```env
   BOT_TOKEN=ваш_токен_від_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```
4. Запустіть бота:
   ```bash
   python main.py
   ```
